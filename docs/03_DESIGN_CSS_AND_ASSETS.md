### ২. একীভূত বিশাল CSS ফাইল (Monolithic CSS)
- **ফাইল:** [`dc-hall/css/style.css`](file:///c:/Users/USER/Downloads/%23%23aicode/DC-hall%20(sanity)/dc-hall/css/style.css)
- **সাইজ:** ~১৪৫ KB (হাজার হাজার লাইনের বিশাল একক ফাইল)।
- **সমস্যা:** হেডার, ফুটার, হোমপেজ, রুমমেট কার্ড, জন্মদিন গ্রিড, স্টুডেন্ট মোডাল—সবকিছু একই ফাইলে থাকায় কোনো একটা পরিবর্তন করতে গেলে অন্য পেজের ডিজাইন ভেঙে যাওয়ার ঝুঁকি তৈরি হয়।
- **মডুলার CSS রোডম্যাপ:**
  ```
  css/
  ├── variables.css      # কালার প্যালেট (#00d084, dark theme), ফন্ট, শ্যাডো
  ├── base.css           # রিসেট, টাইপোগ্রাফি, স্ক্রলবার
  ├── layout.css         # নেভবার, ফুটার, রেসপনসিভ কন্টেইনার
  ├── components/
  │   ├── cards.css      # স্টুডেন্ট কার্ড, রুমমেট কার্ড, বার্থডে পিলস
  │   ├── modals.css     # স্টুডেন্ট ও রুম গ্যালারি মোডাল
  │   └── buttons.css    # গ্লাস ইফেক্ট বাটন, ফিল্টার বাটন
  └── pages/
      ├── home.css       # হিরো সেকশন, কাউন্টার, ব্যানার
      ├── roommates.css  # ২-কলাম ও ৩-কলাম গ্রিড ভিউ
      └── results.css    # পিডিএফ ভিউয়ার ও রেজাল্ট টেবিল
  ```

### ৪. রেসপন্সিভ ডিজাইন ও মোবাইলে ব্রেকপয়েন্ট রুলস
- **ডেস্কটপ (≥ 860px):** রুমমেট ডিটেইল্ড ভিউ ২-কলাম (`repeat(2, minmax(0, 1fr))`), প্যারালাল ভিউ ৩-কলাম।
- **ট্যাবলেট (581px – 859px):** ২-কলাম গ্রিড।
- **মোবাইল (≤ 580px):** বাধ্যতামূলক `1fr !important` (Full Width), `box-sizing: border-box !important` যাতে কোনো অনুভূমিক স্ক্রল (horizontal blowout) না হয়।
